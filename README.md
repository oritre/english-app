# אנגלית צעד צעד

שיעורי אנגלית קצרים לדוברי עברית, בסגנון דואלינגו. אפליקציית ווב (PWA) שעובדת באנדרואיד, במחשב ואופליין, בלי שרת ובלי חשבון.

- כמה לומדים על אותו מכשיר, לכל אחד התקדמות משלו
- בכניסה ראשונה: להתחיל מההתחלה או מבחן רמה שמקפיץ לשיעור המתאים (אפשר לחזור עליו בכל זמן)
- מסלול של יחידות ושיעורים, כל שיעור 11-12 תרגילים
- תרגילים: בחירת מילה, תרגום עם בנק מילים (בשני הכיוונים), התאמת זוגות, השלמת משפט, הקשבה והקלדה, הקשבה ותרגום (עברית ואנגלית, בלי להציג את הטקסט), דיבור עם תמלול (צריך 100% מהמילים), ומיחידה 3 גם כתיבה חופשית בלי אריחים
- מילים חדשות מסומנות בקו מקווקו: לחיצה מציגה פירוש ומקריאה באנגלית ובעברית
- הסבר דקדוק אוטומטי כשהטעות נובעת מדקדוק (סדר מילים, a/an, am/is/are, has/have, s בסוף פועל, can to, מילות יחס)
- טעויות חוזרות בסוף השיעור, XP, יעד יומי ורצף ימים, ליגות שבועיות
- 5 יחידות (Pre-A1 עד A2), ובסוף כל יחידה שלב בונוס של אנסין: קטע קריאה עם שאלות הבנה, רק עם מילים שנלמדו
- דוח התקדמות לכל לומד
- הקראה ותמלול דרך הדפדפן (Web Speech API, בלי מפתחות API)
- ההתקדמות נשמרת במכשיר (IndexedDB), ואפשר לסנכרן בין מכשירים עם קוד משפחה

## הרצה מקומית

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## סנכרון בין מכשירים (Firebase, פעם אחת)

1. ב־[Firebase Console](https://console.firebase.google.com) יוצרים פרויקט (בלי Analytics).
2. Build > Firestore Database > Create database, במצב Production, באזור `eur3` (או הקרוב).
3. בלשונית Rules מדביקים את הכללים מ־`firestore.rules` ולוחצים Publish.
4. Project settings > General > Your apps > Web (`</>`), נותנים שם ומעתיקים את אובייקט `firebaseConfig`.
5. מדביקים אותו ב־`js/firebaseConfig.js` במקום `null`, ודוחפים לגיטהאב.

אחרי זה, בכל מכשיר: לומדים > 🔄 סנכרון בין מכשירים. במכשיר הראשון יוצרים קוד משפחה, ובשאר מקלידים אותו. כל מי שיודע את הקוד רואה ומשנה את הנתונים של המשפחה, אז לא משתפים אותו מחוץ לבית. החבילה החינמית של Firebase מספיקה בהרבה לשימוש משפחתי.

## תוכן

השיעורים כתובים ב־`tools/build_content.py` ונבנים ל־`data/`:

```bash
python3 tools/build_content.py
node --test tests/logic.test.mjs
```

הטסט בודק שכל שיעור תקין ושכל תשובה אפשר להרכיב מהאריחים שלה.

### חשיבה ומדעים (בסגנון בריליאנט)

לשונית שנייה במסך הבית: קטלוג קורסים (משוואות, שברים, תבניות, היגיון, קוד, הסתברות, גאומטריה, מדע) שלומדים בהם תוך כדי פתרון: מאזניים, פיצות לצביעה, ציר מספרים, רובוט שמתכנתים, מיון לקבוצות, זוויות והטלות קובייה. לכל שאלה רמז והסבר. ה־XP, הרצף והליגה משותפים לאנגלית.

```bash
python3 tools/think_content.py   # data/think.json + data/lessons/t-*.json
```

### ידע כללי (בסגנון בריין פופ)

לשונית שלישית: נושאים לפי כיתה. כל שיעור הוא סרטון אמיתי בעברית מערוץ שאושר (מכון דוידסון, משימת רקיע, הילימוד, 929; `tools/know_videos.py`), ואחריו חידון אמריקאי קצר. השאלות מותאמות לכיתה של הילד: לכל סרטון יש שאלות לפי שכבות כיתה, וכל לומד מקבל את השכבה שלו (`forGrade` ב-`js/storyLogic.js`). נושא בלי סרטון מאושר לא מוצג.

הסרטונים לא מתנגנים מיוטיוב. התוסף `pi/english_media` ל-Home Assistant בפאי מוריד כל סרטון פעם אחת (yt-dlp) ומגיש אותו בכתובת https ציבורית דרך Tailscale Funnel (`https://english-media.tailafe754.ts.net`). כך אין פרסומות, הסרטונים עובדים בכל מקום, ובהומגארד צריך לפתוח רק את הכתובת הזאת (`/always`). השרת מגיש סרטון רק עם מפתח שנגזר מקוד המשפחה של הסנכרון (`js/media.js`), ולכן מכשיר בלי קוד משפחה לא יקבל אותו.

התקנת התוסף: מעתיקים את `pi/english_media` לשיתוף `addons` בפאי, ובחנות התוספים של HA בוחרים ⋮ ← Check for updates ← English app videos ← Install. בהגדרות התוסף ממלאים `family_code` (קוד המשפחה) ו-`tailscale_authkey` (מפתח מ-Tailscale admin ← Settings ← Keys). בדיקה: `/status` בכתובת התוסף.

```bash
python3 tools/know_content.py   # data/know.json + data/lessons/k-*.json
```

התכנון (recon, ארכיטקטורה, טבלת פיצ'רים) נעשה עם [Replica](https://github.com/Jakeschincariol/replica-skill) ונמצא ב־`replica/`.
