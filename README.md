# אנגלית צעד צעד

שיעורי אנגלית קצרים לדוברי עברית, בסגנון דואלינגו. אפליקציית ווב (PWA) שעובדת באנדרואיד, במחשב ואופליין, בלי שרת ובלי חשבון.

- מסלול של יחידות ושיעורים, כל שיעור 11-12 תרגילים
- תרגילים: בחירת מילה, תרגום עם בנק מילים (בשני הכיוונים), התאמת זוגות, השלמת משפט, הקשבה והקלדה
- טעויות חוזרות בסוף השיעור, XP, יעד יומי ורצף ימים
- הקראה באנגלית דרך הדפדפן (בלי מפתחות API)
- ההתקדמות נשמרת במכשיר (IndexedDB)

## הרצה מקומית

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## תוכן

השיעורים כתובים ב־`tools/build_content.py` ונבנים ל־`data/`:

```bash
python3 tools/build_content.py
node --test tests/logic.test.mjs
```

הטסט בודק שכל שיעור תקין ושכל תשובה אפשר להרכיב מהאריחים שלה.

התכנון (recon, ארכיטקטורה, טבלת פיצ'רים) נעשה עם [Replica](https://github.com/Jakeschincariol/replica-skill) ונמצא ב־`replica/`.
